## Getting Started

### Accessing the System

1. Log in to the admin panel at `https://your-homefinder-domain.example/admin`
2. As a Head Division, you'll see the dashboard with an overview of your division's work
3. Navigate using the left sidebar menu

### Understanding Your Role

**Head Division** is a leadership role that provides:
- **Full assignment flexibility**: You can assign tickets and add members to projects for **anyone** in the organization
- **Division visibility**: You can see and manage all daily todos from employees in your division
- **Team oversight**: You can monitor your division members' work and progress

**Key Differences from Regular Users**:
- ✅ Can assign tickets to anyone (not restricted to specific roles)

## Understanding Your Role

### What is Head Division?

Head Division is a leadership role that bridges management and team members. You have enhanced privileges to:
- Manage your division's projects and tickets
- Assign work to anyone in the organization
- Oversee daily todos from division members
- Coordinate between C-Level executives and team members

### Role Hierarchy

**Assignment Flow**:
```
C-Level (CEO, COO, CTO, HR)
    ↓ (can only assign to)
Head Division
    ↓ (can assign to)
Anyone (Regular Users, Team Members)
```

**Your Position**:
- **Receive assignments from**: C-Level roles (CEO, COO, CTO, HR)
- **Can assign to**: Anyone in the organization (no restrictions)
- **Manage**: Your division members' work and daily todos

### Your Permissions

As a Head Division, you can:
- ✅ Create and manage projects
- ✅ Add anyone to projects (no role restrictions)
- ✅ Assign tickets to anyone (full flexibility)
- ✅ View and manage all daily todos from your division members
- ✅ View division-wide analytics
- ✅ Create, edit, and delete tickets in your projects
- ✅ Manage team members in your projects

## Division Management

### Understanding Your Division

Your division is a group of employees that you oversee. Each division has:
- **Division Name**: Identifies your team (e.g., "Engineering", "Marketing", "Sales")
- **Division Members**: All employees assigned to your division
- **Division Head**: You, as the Head Division manager

### Viewing Your Division Members

1. Navigate to **Users** in the navigation menu
2. Use filters to see your division members:
   - Filter by **Division** to see all members in your division
   - You'll see their daily todos, project assignments, and ticket assignments

### Managing Division Members

**What You Can Do**:
- View all division members' daily todos
- Assign tickets to division members
- Add division members to projects
- Monitor division members' progress
- View division-wide analytics

**What You Cannot Do**:
- Edit user profiles (contact Super Admin)
- Change user roles (contact Super Admin)
- See daily todos from other divisions (only your division)

## Project Management

### Creating Projects

1. Navigate to **Projects** in the navigation menu
2. Click **"New Project"** button
3. Fill in the project details:
   - **Name**: Project name (e.g., "Website Redesign")
   - **Description**: Detailed project description
   - **Ticket Prefix**: Short code for ticket IDs (e.g., "WEB", "MOB")
   - **Start Date**: Project start date (optional)
   - **End Date**: Project end date (optional)
4. Click **"Create"** to save

### Adding Team Members to Projects

**As Head Division, you have full flexibility**:

1. Open a project
2. Go to the **Members** tab
3. Click **"Add Member"**
4. Select users from the dropdown

**Key Advantage**: Unlike C-Level roles, you can add **anyone** to projects:
- ✅ Regular team members
- ✅ Other Head Division members
- ✅ C-Level executives
- ✅ Anyone in the organization

**No Restrictions**: You'll see a helper message: "Head Division can assign to any project member"

### Managing Project Settings

- **Pin Projects**: Pin important projects to show them at the top in timeline views
- **Project Notes**: Add notes or documentation directly in projects
- **Ticket Statuses**: Configure workflow statuses for the project
- **Epics**: Organize tickets into larger initiatives

## Ticket Assignment and Management

### Creating Tickets

1. Navigate to **Tickets** or click **"New Ticket"** from the Kanban board
2. Fill in the ticket form:
   - **Project**: Select the project
   - **Name**: Clear, descriptive ticket title
   - **Description**: Detailed description
   - **Status**: Initial status (usually "To Do")
   - **Priority**: Set priority level
   - **Epic**: Optionally assign to an epic
   - **Assignees**: Select one or more team members
   - **Start Date**: When work should begin (optional)
   - **Due Date**: Target completion date (optional)
3. Click **"Create"**

### Assigning Tickets

**Your Assignment Privileges**:

As Head Division, you can assign tickets to **anyone** in the organization:
- ✅ Regular team members
- ✅ Other Head Division members
- ✅ C-Level executives
- ✅ Anyone in any project

**No Restrictions**: You'll see a helper message: "Head Division can assign to any project member"

**How to Assign**:
1. Create or edit a ticket
2. In the **Assignees** field, select one or more users
3. You'll see all available users (no filtering based on role)
4. Select who you want to assign the ticket to
5. Click **"Save"**

**Best Practices**:
- Assign tickets to division members for work coordination
- Assign tickets to appropriate team members based on skills
- Use multiple assignees for collaborative work
- Set clear due dates for priority work

### Receiving Assignments from C-Level

When C-Level roles (CEO, COO, CTO, HR) assign tickets to you:
- You'll receive notifications
- The ticket will appear in your dashboard
- You can then assign it to appropriate team members
- This is the standard workflow: C-Level → Head Division → Team Members

**Workflow Example**:
1. CEO assigns a ticket to you (Head Division)
2. You receive notification and review the ticket
3. You assign it to appropriate team members in your division
4. Team members work on the ticket
5. You monitor progress and coordinate completion

### Managing Ticket Assignments

**Reassigning Tickets**:
- You can reassign tickets to different team members
- Useful when workload needs redistribution
- Helpful when team members are unavailable

**Multiple Assignees**:
- Assign tickets to multiple team members for collaboration
- All assignees can view and update the ticket
- Useful for cross-functional work

## Daily Todos Management

### Overview

As Head Division, you have enhanced visibility into your division members' daily todos. You can:
- View all daily todos from employees in your division
- Create daily todos for division members
- Update and manage division members' todos
- Monitor division workload and progress

### Accessing Daily Todos

1. Navigate to **Daily Todos** in the navigation menu
2. You'll see a list of all daily todos from your division members
3. Use filters to organize your view

### Viewing Division Members' Todos

**What You Can See**:
- ✅ All daily todos from employees in your division
- ✅ Your own daily todos
- ❌ Daily todos from other divisions (not visible)

**The Daily Todos List Shows**:
- **User**: Employee name and division
- **Date**: Todo date
- **Title**: Todo title
- **Description**: Brief description preview
- **Status**: Current status with color coding
  - **Gray**: Pending
  - **Yellow**: In Progress
  - **Green**: Done

### Creating Daily Todos for Division Members

**To Create a Todo for a Division Member**:

1. Navigate to **Daily Todos**
2. Click **"New To-Do"** button
3. Fill in the form:
   - **User**: Select a division member (you'll see all users, but focus on your division)
   - **Date**: Select the date for the todo
   - **Title**: Clear, descriptive title (required)
   - **Description**: Detailed description (optional)
   - **Status**: Initial status (Pending, In Progress, or Done)
4. Click **"Create"**

**Use Cases**:
- Assigning daily tasks to team members
- Creating follow-up reminders
- Setting daily goals for employees
- Coordinating division workload

### Managing Division Members' Todos

**Viewing and Editing**:

1. Navigate to **Daily Todos**
2. Browse the list or use filters:
   - **Filter by User**: See todos for specific division members
   - **Filter by Division**: See todos from your division (default)
   - **Filter by Date**: Focus on specific dates
   - **Today's Todos**: Quick filter for today
   - **Filter by Status**: Pending, In Progress, or Done
3. Click on any todo to view details
4. Click **"Edit"** to modify:
   - Title and description
   - Status
   - Date
   - Assign to different user (if needed)

### Deleting Division Members' Todos

1. Open a daily todo from a division member
2. Click **"Delete"** button
3. Confirm deletion

**Note**: You can delete todos from your division members. You cannot delete todos from other divisions.

### Daily Todos Dashboard Widget

**Daily Todo Division Widget**:
- Displays a table of todos from your division members
- Shows user, date, title, and status
- Includes filtering capabilities
- Updates in real-time

**Use It To**:
- Monitor division productivity
- Track daily task completion
- Identify employees who need support
- Review division workload distribution

### Best Practices for Daily Todos Management

**Division Coordination**:
- Review division todos regularly to understand workload
- Help balance workload across team members
- Support employees with too many pending todos
- Recognize employees with consistent completion

**Communication**:
- Use daily todos to coordinate daily standups
- Link todos to project tickets when relevant
- Encourage employees to keep todos updated
- Provide feedback on todo completion

## Troubleshooting

### I Can't Assign Tickets to Some Users

**Possible Causes**:
- The user might not be a project member
- There might be a system error

**Solutions**:
1. Verify the user is added to the project (Members tab)
2. Check if the user exists in the system
3. Refresh the page and try again
4. Contact Super Admin if the issue persists

**Note**: As Head Division, you should be able to assign to anyone. If you're seeing restrictions, there might be a system configuration issue.

### I Can't See Daily Todos from Other Divisions

**This is Expected**:
- Head Division can only see daily todos from their own division
- You cannot see todos from other divisions
- This is by design for division privacy

**If You Need Cross-Division Visibility**:
- Contact Super Admin, Admin, CEO, COO, CTO, or HR
- Management roles have full visibility across all divisions

### I Can't Add Members to a Project

**Possible Causes**:
- You might not have permission for that project
- The user might not exist
- There might be a system error

**Solutions**:
1. Verify you're the project creator or have management permissions
2. Check if the user exists in the system
3. Refresh the page and try again
4. Contact Super Admin if the issue persists

**Note**: As Head Division, you should be able to add anyone to projects. If you're seeing restrictions, there might be a system issue.

### Team Members Can't See Projects

**Possible Causes**:
- They haven't been added as project members
- They might not have the correct role permissions

**Solutions**:
1. Add them as project members (Members tab)
2. Verify their role permissions
3. Contact Super Admin if needed

### Daily Todos Not Showing for Division Members

**Possible Causes**:
- The user might not be in your division
- The todos might be from a different date range
- There might be a filter applied

**Solutions**:
1. Verify the user's division matches yours
2. Clear any filters and check date range
3. Refresh the page
4. Contact Super Admin if the issue persists
