# Product Overview

DewaKoding Project Management is a comprehensive Laravel-based project management and HRIS system built on Filament 3.

## Core Features

**Project Management**

-   Project and ticket tracking with customizable statuses
-   Kanban board view with drag-and-drop
-   Epic management for organizing related tickets
-   Timeline/Gantt visualization
-   Multi-user ticket assignments
-   Comment system for collaboration
-   External client portal for project visibility
-   Weekly todo management with division-based organization

**HRIS Module (Phase 1)**

-   Employee data management (profiles, documents, movements)
-   Organizational structure (departments, positions, hierarchies)
-   Leave management (annual, maternity, paternity) with Indonesian labor law compliance
-   Configurable approval workflows
-   Time and attendance tracking
-   API for employee self-service (ESS) and mobile apps

**Access Control**

-   Role-based permissions using Filament Shield and Spatie Permission
-   Division-based access control with head division roles
-   Fine-grained policies for all resources

**Integrations**

-   Google OAuth authentication
-   Email notifications via queue system
-   Export functionality (CSV, Excel, PDF)
-   Sanctum API for mobile/external access
